Selection Rule: For residential replacements, match existing pump's connection size and head. For new installs, calculate head: ΔP = (pipe length × 0.03) + (fittings × 0.3) + static head. Flow: Q = heat load (kW) / (1.16 × ΔT). Standard ΔT = 10°C (heating) or 5°C (UFH).

Pump not running? ├── No power? → Check breaker → Check wiring → Test voltage └── Has power but not running? ├── Humming? → Seized impeller → Remove rotor, clean, reinstall └── Silent? → Electronics fault → Check E-codes → Contact support Pump running but no flow? ├── Valves closed? → Open isolation valves ├── Air lock? → Vent pump (vent screw 1-2 turns) └── Blocked? → Check impeller → Inspect strainer/filter Excessive noise? ├── Air in system? → Full venting procedure ├── Shaft not horizontal? → Reinstall pump └── Bearing wear? → Check rotor play → Replace if >0.5mm Modbus not communicating? ├── A/B swapped? → Verify A→A, B→B ├── Wrong baud rate? → Set 9600/8N1 └── Address conflict? → Set unique slave address (1-247)

📡 Modbus RTU BMS Integration Guide

For Hero Pump HRB and HRZL series with Modbus RTU (RS-485). Enables BACS/SRI compliance and remote monitoring.

🔌 Wiring

TerminalSignalWire Color
A (D+)Modbus Data +White / Green
B (D-)Modbus Data -Black / Red
GNDSignal GroundShield / Bare
Do NOT connect A to B or GND to A/B. Daisy-chain topology (NOT star). Max 32 devices per bus. Termination resistor 120Ω at last device.
