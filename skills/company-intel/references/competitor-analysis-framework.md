# AI 外贸同行竞品分析框架

## 背调维度（6 维评分）

| 维度 | 检查项 | 红旗信号 |
|------|--------|---------|
| 创始人身份 | 真实姓名/LinkedIn/背景 | 完全匿名、无法验证 |
| 公司注册 | 工商注册/统一社会信用代码 | 无注册信息、个人工作室 |
| 数据一致性 | 首页 vs About 页数据 | 数字前后矛盾 |
| 技术深度 | 网站技术栈/自动化实现 | 仅 WordPress + AI 调用 |
| 客户案例 | 第三方背书/可验证案例 | 仅脱敏自营案例 |
| 融资/资本 | Crunchbase/IT桔子记录 | 无融资、无资本背书 |

## 价值链条定位分析

```
流量 → 内容 → 询盘 → 报价 → 成交 → 复购
 ↑              ↑                    ↑
内容生成商      灰色地带              成交转化系统
```

**越靠近"成交"端，离钱越近，价值越高。**

## 常见模式识别

| 模式 | 特征 | 风险 |
|------|------|------|
| 个人顾问型 | 匿名创始人、微信私域、咨询费定价 | 交付能力受限、无规模化可能 |
| 站群流量型 | 批量建站、SEO/GEO 内容 | AI 让内容成本趋近于零，护城河消失 |
| 平台亲儿子 | 阿里 Accio Work 等内置工具 | 依赖平台生态，第三方无法接入核心 API |

## 关键判断标准

**谁更值钱？** 离钱近的那个。

- 卖"内容批量生产"（漏斗最上层）= 可替代性高，因为 AI 让内容生产成本趋近于零
- 做"询盘到成交"（漏斗中下层）= 粘性强，嵌入业务流程后替换成本巨大
- 依赖平台内部接口（非开放 API）= 亲儿子独占，第三方无法竞争
